# Quality-Assurance-Testing
A collection of projects related to Quality Assurance &amp; System Testing


* LSP Mini Robot Challenge: Went over an introduction to Lego Spike Prime. Built a 2 wheel base for a robot, and then programmed it to test its movement around a simple track. Completed 4 attempts using the engineering design process to evaluate each test. The teaching presentation and test script is included.
    * Used: Creating Lesson, Teaching Lesson, Lego Building, Lego Spike Prime, Engineering Design Process, Functional Testing, Test Script Documentation
